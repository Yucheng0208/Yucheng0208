## 關於我

我目前就讀國立清華大學資訊工程學系博士班，同時擔任龍華科技大學講師。研究聚焦於人工智慧、電腦視覺與物聯網的應用，致力於把研究成果做成真正能落地的系統，涵蓋手語辨識、交通安全與智慧教育等領域。我也帶領 [ICI Lab（智慧運算與資訊安全實驗室）](https://www.yucheng208.net/ici-lab)，專注於智慧運算、電腦視覺與資訊安全研究。
